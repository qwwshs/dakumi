# 声纹图使用说明

声纹图从左到右表示频率从低到高，沿着编辑区上下移动表示播放时间。颜色表示当前时间和频率上的声音强度。频率尺显示当前频率范围的位置刻度。

## 开始使用

在侧边栏打开“设置”，勾选“声纹图”。各项选择会立即应用，最后点击设置页的保存按钮即可保留到下次启动。

频率尺默认收起。点击 x、w、lpos、rpos 信息行最右侧的展开按钮后，可以在其下方显示频率刻度。在刻度上滚动可以围绕鼠标指向的位置缩放；按住 Shift 滚动可以左右移动显示范围。编辑区的滚轮仍控制节拍。

“左端频率”和“右端频率”可以输入要看的频率范围（Hz）。选择“音名 / MIDI”会按音乐音阶排列频率，适合找音高和泛音；“频率（低音展开）”适合检查一般频谱；“频率（均匀间隔）”让每增加相同 Hz 都占据相同画面宽度，更适合比较绝对频率差。

“亮度增益”只调整声纹颜色，不改变播放音量。“显示下限”和“显示上限”决定颜色映射到多大的声音范围。下限以下透明，上限以上使用最亮颜色。缩小 dB 范围会增加对比度；如果底噪也变亮，就降低增益或提高显示下限。图像不会根据当前这一屏的最响声音自动变色，所以不同片段之间可以直接比较。

## 选择分析方式

| 设置中的名称 | 使用场景 | 分析窗口 |
|---|---|---:|
| 鼓点起止 | 查看很短的敲击、爆破音和起音位置 | 2048 点，步长 128 点 |
| 均衡 | 查看普通频谱，兼顾音高与时间细节 | 4096 点，步长 128 点 |
| 谐波分线 | 区分旋律音、泛音和彼此接近的音高（默认） | 16384 点，步长 128 点 |
| 低音细节 | 查看低音区里相隔很近的音 | 32768 点，步长 256 点 |

以 44.1 kHz 的音频为例，16384 点窗口约覆盖 0.37 秒，每个 FFT 频率格相隔约 2.69 Hz；32768 点窗口约覆盖 0.74 秒，每格约 1.35 Hz。短窗口的时间定位更准。长窗口包含更长的声音片段，短音看起来会拖得更长；鼓点模式的窗口约 0.046 秒，适合检查快速变化。

频率格的间隔不等于一定能分开的音高间距。实际能否看清两条线还取决于窗函数、声音长度、噪声、颤音和录音本身。例如低音区一个半音的频率差很小，需要较长音符和“低音细节”模式才能分开。“音名 / MIDI”只改变显示刻度，不能凭空增加分析精度。

## 窗函数与颜色

“分线优先”使用 Hann 窗。它让一个单频峰更窄，适合查看挨得近的旋律音；离强音较远的弱泛音仍保留在完整频谱里。

“弱音优先”使用 Blackman-Harris 窗。它能减少强音旁边扩散开的杂光，让较弱的泛音更显眼，但峰本身更宽一些。这两种窗都不会用短窗结果替换长窗的频谱。

声音能量先以双精度计算，再作为完整的线性功率保存；选定显示范围后才转换成分贝和颜色。立体声按两侧的声音能量合并，左右反相也不会被错误抵消。频率缩小到屏幕宽度时保留其覆盖范围内最强的频率格，时间缩小到较少像素时则检查并汇总覆盖时段内的分析帧，防止跳过短促的声音。

不同分析方式的窗口宽度不同：旋律音的强度在各模式间更容易比较，宽频噪声的颜色可能改变，因为每格覆盖的频率范围变了。声纹颜色表示单格能量，不等同播放器音量或人的响度；比较曲目片段时，尽量使用相同的分析方式、频率范围和 dB 显示范围。

单个分析窗口的采样点步进固定，同一区域在不同帧或缩放比例下使用相同的音频采样位置。音频分析在后台进行，最多保留约 96 MiB 的分析数值供回看；因此刚跳到远处时，声纹会先出现一部分，再逐步补齐。 GPU 浮点纹理负责保存屏幕所需数值，分贝换算与颜色映射在绘制时由着色器完成。调整颜色不会重新分析音乐，缩放频率也只重新读取已保留的频谱。

本功能绘制的是 STFT 频谱和频率刻度。频率尺不会自动追踪旋律，也不会修复噪声或分离乐器；录音中很弱的细节如果已被混音或编码抹掉，单纯放大显示也无法恢复。
