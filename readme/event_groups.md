# 事件组

事件组把一组 x、w、lpos、rpos 变化保存为可复用的动作。放入谱面的是对这个组的引用：同一个组可以放在不同轨道、不同时间，并调整大小或翻转。音符仍单独放置。

## 制作和编辑

1. 在侧边栏打开“事件组”，输入名称并新建。名称必须非空，不能带换行、斜杠等字符，同名组不能被改名覆盖。
2. 点击组名，进入专用编辑模式：edit 区只有该组的一条轨道，demo 只预览这一组；标签页暂时不可用。
3. 像编辑普通轨道一样，在事件栏按两次 `E` 放置事件，按 `D` 删除，也可框选、批量修改及撤销重做。组内只保存轨道事件，不能嵌套放另一个事件组。
4. 点击“退出事件组编辑”，或通过切换轨道退出。组内修改合并回原谱面；退出后的整次组编辑可以在主谱面历史中撤销。
5. 手动或自动保存时也会同步正在编辑的组，无需先退出。

## 放到谱面中

![事件组从 2 至 6 拍映射到 10 至 18 拍，并将位置 0 至 100 映射到 20 至 80](images/event-group-placement.png)

上图展示动作复用后的时间与位置换算；实例覆盖范围内，同轨道的其他事件不能与它重叠。


回到普通谱面，把鼠标放在事件栏：第一次按 `T` 确定起点，再移动到终点按 `T` 完成。点击这个引用，在侧边栏选择要使用的事件组，并填写起始值 `from` 与终点值 `to`。

| 设置 | 作用 |
| --- | --- |
| 事件组 `event_group` | 选择组名；未选择、名称不存在或组为空时，按 x 从起始值到终点值线性变化 |
| 起始值 `from` / 终点值 `to` | 把组内按偏好换算后的数值映射到这个范围；不是单独移动组的起点坐标 |
| 水平翻转 `flip_horizontally` | 镜像位置变化；w 不翻转，lpos 与 rpos 互换角色 |
| 时间翻转 `flip_vertically` | 从组的末尾往开头读取动作 |

事件组占用该轨道从起点到终点的时间段。这段时间内，任何事件栏都不能再放普通事件或另一事件组；边界相接可以放置，其他轨道和音符不受影响。

例如，组内动作从第 2 拍持续到第 6 拍，放置的引用从第 10 拍持续到第 18 拍，则整组 4 拍的动作变成 8 拍。默认偏好下，组内位置 0、50、100，若引用的起始值为 20、终点值为 80，则分别变为 20、50、80。

组内各事件仍保留自己的缓动。时间范围取所有组内事件的最早起点和最晚终点；位置类数值扣除谱面偏移后除以事件缩放，宽度只除以事件缩放。水平和时间翻转作用于有效组的读取，缺失组的线性替代行为不应用组内翻转。

## 修改组名或删除

改名时，当前谱面中引用旧名称的实例会一起改名。删除定义后，已有实例保留，按上表中的线性变化处理；可以撤销删除恢复原组。修改一个组会影响所有引用它的实例。

开发者需要的 JSON 字段和换算公式见 [开发者指南](../DEVELOPER_GUIDE.md#事件组格式与计算)。
