# 轨道初始值

在侧栏“轨道 → 编辑”中设置 `start_x`、`start_w`、`start_lpos`、`start_rpos`。这四个字段使用与 event 相同的位置单位；默认全部留空，旧谱面保持原来的零初始值。

填写两个属性即可，可使用 x/w、lpos/rpos，也可混合位置、中点和宽度。未填写的属性不参与初始值选择，填写 `0` 则是有效数值。清空输入框会删除相应字段；非数字输入不会覆盖已有值。

在当前时间读不到某属性的 event 时，使用对应初始值补位。尚未开始的 event 不会提前覆盖初始值；结束的 event 继续保持终值。初始值与读取到的事件按现有合并规则，最终只取两个属性计算 x/w：

- 已读取到的 event 优先，多个 event 按最近的时间选择。
- 不足两个 event 时，用填写的初始属性补齐。
- 初始属性超过所需数量时，按 x、w、lpos、rpos 顺序取用。
- 无初始值可用时，用零补齐。

例如 `start_lpos = 20`、`start_rpos = 80` 得到 x=50、w=60；lpos 事件开始后，采用其当前值与初始 rpos 合并。两个属性都有 event 时，初始值不再参与。

初始值计算后继续应用父轨道和边界规则。即使轨道没有 note 或 event，只要填写了初始值，也会出现在轨道列表和预览中。字段保存在 `chart.track`，修改与清空支持撤销、重做及重新打开页面。
