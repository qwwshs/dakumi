# 自定义过渡

自定义过渡让你用 Lua 编写一段计算过程，改变 event、effect 和事件组内部事件的变化曲线。

## 在编辑器中使用

1. 点击侧边栏的“自定义过渡”。
2. 填写名称，在多行文本框里写脚本，点击“保存”。按 Enter 可以换行。
3. 打开事件或效果的属性页，将过渡类型切换为“自定义过渡”，选择刚才保存的名称。
4. 再次打开“自定义过渡”并点击名称，可以修改脚本。点击“删除”移除定义。

修改和删除可以撤销、重做。定义保存在当前谱面内，不影响其他谱面。事件组内部编辑也可以使用当前谱面的定义；新增、修改或删除定义前先退出事件组编辑。

开启 event 直观编辑后，右键菜单中的“切换过渡类型”依次切换 bezier、easings、自定义过渡。自定义模式下，“下一个 / 上一个曲线类型”按名称顺序选择定义；首次切入时自动选择第一个定义，没有定义时使用线性过渡。

## 怎样写脚本

脚本是函数的内部内容，不需要写 `function(t)`。编辑器提供输入 `t`，范围为 0 到 1。用 `return` 返回一个数值：返回 0 对应起始值，返回 1 对应结束值，其他数值按比例计算。

例如，先慢后快：

```lua
return t * t
```

例如，先快后慢：

```lua
local remaining = 1 - t
return 1 - remaining * remaining
```

实际结果为 `from + (to - from) × 脚本返回值`。例如 from=10、to=30，脚本返回 0.25，实际值就是 15。

返回值允许小于 0 或大于 1，这样可以做越过起点或终点的效果。若希望曲线准确从起点到终点，请让 t=0 时返回 0，t=1 时返回 1。

脚本可以使用局部变量、条件、循环、局部函数和常用 `math` 数学方法，例如 `math.sin`、`math.pi`、`math.min`、`math.max`。不提供文件、系统、网络、模块加载、随机数和编辑器对象访问；不允许修改全局变量或数学库。字符串库也不可用。

名称未找到时使用线性过渡。语法错误、运行错误、死循环、返回非数值或无限值时，也会退回线性过渡。编辑页会显示脚本错误。保存前会检查几个进度位置，运行时也有指令和内存检查，出错的脚本停止执行直到内容被修改。

## 谱面文件写法

```json
{
  "custom_trans": {
    "square": "return t * t"
  },
  "event": [
    {
      "track": 1,
      "type": "x",
      "beat": [0, 0, 1],
      "beat2": [4, 0, 1],
      "from": 0,
      "to": 100,
      "trans": {"type": "custom", "custom": "square"}
    }
  ]
}
```

- `custom_trans`：名称与 Lua 脚本组成的字典。
- `trans.type`：填写 `custom`，与 `bezier`、`easings` 并列。
- `trans.custom`：要使用的定义名称。

名称最多 128 字节，不能为空或包含控制字符、斜杠；脚本最多 16384 字节。多行脚本在 JSON 字符串里以 `\n` 保存，使用编辑器保存时会自动处理。
